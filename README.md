# IMPORTec AI Campaign Manager

Modelo profesional de aplicativo web para la gestión de campañas de contenidos con inteligencia artificial simulada para **IMPORTec Ayacucho**.

## Objetivo
Planificar, crear, organizar, publicar, medir y optimizar campañas digitales para productos tecnológicos: computadoras, laptops, accesorios, impresoras y servicios técnicos.

## Tecnologías
- HTML5
- CSS3
- JavaScript puro
- Estructura lista para GitHub Pages
- Recursos gráficos locales en SVG y PNG

## Módulos
1. Inicio profesional
2. Dashboard de indicadores
3. Gestión de campañas
4. Generador de contenido con IA simulada
5. Catálogo de productos tecnológicos
6. Calendario editorial
7. Reportes y métricas
8. Repositorio de contenidos
9. Configuración institucional

## Instalación
Descargue el repositorio, descomprima el archivo y abra `index.html` en el navegador. También puede subir la carpeta a GitHub y activar GitHub Pages.

## Uso académico
Este modelo permite exponer un proyecto completo de aplicación web con diseño moderno, navegación interna, formularios validados, dashboards, tablas, gráficos visuales y contenido marketero adaptado a IMPORTec Ayacucho.
